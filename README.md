# Exercício 00

Introdução ao HTML básico, incluindo títulos, parágrafos, listas, imagens, linhas horizontais e links.

## Conteúdo
- HTML semântico mínimo
- Listas ordenadas e não ordenadas
- Inserção de imagens
- Hiperligações externas
- Vídeo incorporado

## Como visualizar
1. Abrir a pasta do exercício em um navegador.
2. Carregar o ficheiro `index.html` diretamente ou servir a pasta localmente com um servidor simples.

## Objetivo
Familiarizar-se com os elementos fundamentais do HTML e com a forma como a página se compõe em blocos estruturados.
